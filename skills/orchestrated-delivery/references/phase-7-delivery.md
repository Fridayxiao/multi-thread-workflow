# Phase 7: Delivery Report And User Acceptance

Read this file when preparing final delivery.

## Goal

Report what was delivered, how it maps to acceptance criteria, what was verified, what risks remain, and how the user can accept or request rework.

## Approach

1. Compare delivered work against `03-acceptance-criteria.md`.
2. Summarize verification evidence.
3. Summarize review findings and how they were handled.
4. State known limitations and residual risks.
5. Provide user acceptance steps.
6. Perform a final consistency check across source-of-truth documents and delivered state.

## Artifact

Create or update `07-delivery-report.md`. Use `template-documents.md`.

## Gate

The workflow is complete only when the user accepts the result or gives rework feedback.

## Rollback

Return to Phase 6 for execution issues, Phase 5 for planning issues, or earlier phases when requirements, solution, or acceptance criteria are wrong.
